Printventory Watcher Options

When you download an STL or 3MF from a model page (same tab), the file is added to Printventory with metadata from the page. No button — download only.

Run Printventory (normal or server mode). It listens on localhost:5000.

When enabled, the extension re-downloads the file and uploads it to Printventory so the file is saved on the server (e.g. NAS). Enable this if Printventory runs in Docker and your library is on a network share. Some sites may block re-download (CORS).

Logs metadata scrapes, downloads, and server calls. Every page logs [Printventory Watcher] Metadata: in the site’s console (F12) with the title we send — you don’t need this checkbox to see that. Background / download logs: chrome://extensions → this extension → Service worker → Inspect.
