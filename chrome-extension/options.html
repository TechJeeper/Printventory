Printventory Watcher

Choose the Printventory data folder — the one that contains printventory.db. The extension writes a PrintventoryInbox folder there. Printventory imports it on launch and every minute.

Windows default: %LOCALAPPDATA%\Printventory\data

No folder selected yet. Inbox files will go to Downloads until you choose one.

Use the toolbar popup on a model page to confirm title/designer. Any download from a supported model site is queued. STL, OBJ, and 3MF are queued from any site.
